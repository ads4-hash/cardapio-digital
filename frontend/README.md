# Frontend — Cardápio Digital

Aplicação Angular 22 (standalone, signals, SSR/hidratação) do cardápio digital.

## Desenvolvimento

```bash
npm start       # http://localhost:4200
```

A API padrão fica em `http://localhost:3000` (`src/app/environment.ts`).

## Build e testes

```bash
npm run build   # build de produção + SSR (dist/)
npm test        # testes unitários (Vitest via @angular/build)
```

Veja o `README.md` da raiz para o projeto completo.
